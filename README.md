# Custom PC Build: Hardware Assembly & Configuration

[![YouTube Demonstration](https://img.shields.io/badge/YouTube-Watch%20Build-red?style=for-the-badge&logo=youtube)](https://youtu.be/)

## Description
A comprehensive documentation repository detailing the physical assembly, component selection, cable management, and initial OS configuration for a custom-built desktop PC. This project highlights hardware compatibility checks, thermal management optimization, and robust system provisioning.

## Hardware Components Used
- **CPU:** AMD Ryzen 5 3600
- **GPU:** NVIDIA GeForce RTX 3060 Ti
- **Motherboard:** Gigabyte B450 Aorus Elite
- **Memory:** 32GB Corsair Vengeance DDR5 (6000MHz)
- **Storage:** 2TB Samsung 970 EVO NVMe M.2 SSD
- **Case:** Corsair 5000X Airflow ATX Mid-Tower
- **Power Supply:** EVGA 650 BQ 80+ Bronze Power Supply

## Software & Utilities Used
- **Windows 11 Pro** (Clean Installation)
- **HWMonitor / Cinebench** (Thermal and Stability Stress Testing)
- **MSI Dragon Center / BIOS Utility** (Fan Curves and XMP/EXPO Tuning)
